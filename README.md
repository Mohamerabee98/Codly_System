# Codly Academy — دليل التشغيل والتعديل

موقع عربي تعريفي لأكاديمية Codly Academy مع مكتبة فيديوهات مقسمة إلى Scratch وPython وWeb Development. المشروع مبني باستخدام HTML وCSS وJavaScript فقط، دون Backend.

## 1) تشغيل الموقع محليًا

يفضل تشغيل الموقع باستخدام خادم محلي بدل فتح ملفات HTML مباشرة:
- في VS Code، ثبّت إضافة **Live Server**.
- افتح مجلد المشروع `codly-academy`.
- اضغط بزر الفأرة الأيمن على `index.html` واختر **Open with Live Server**.

## 2) إضافة شعار الأكاديمية

ضع ملف اللوجو الرسمي داخل:
`assets/logo.png`

إذا كان اسم ملف اللوجو مختلفًا، غيّر مسار `assets/logo.png` في ملفات HTML. ألوان التصميم الحالية مؤقتة إلى أن يتم ضبطها وفق اللوجو الفعلي.

## 3) إضافة فيديو جديد

1. ضع ملف الفيديو داخل المجلد المناسب:
   - `videos/scratch/`
   - `videos/python/`
   - `videos/web/`
2. افتح `js/videos.js` وأضف عنصرًا جديدًا إلى مصفوفة `videos` مع `id` فريد.
3. افتح `js/video-player.js` وأضف بيانات الدرس نفسها إلى مصفوفة `playerVideos`.
4. ضع صورة مصغرة داخل `assets/images/` وحدد مسارها في `thumbnail`.
5. استخدم رابط الدرس مثل `video-player.html?id=python-02`.

مثال على عنصر فيديو:

```js
{
  id: "python-02",
  title: "المتغيرات في Python",
  description: "شرح المتغيرات وأنواع البيانات.",
  category: "python",
  src: "videos/python/lesson-02.mp4",
  thumbnail: "assets/images/python-02.jpg",
  duration: "25 دقيقة",
  lessonNumber: 2,
  level: "مبتدئ",
  symbol: "Py"
}
```

يجب أن تتطابق قيمة `id` بين الملفين `js/videos.js` و`js/video-player.js`، وأن يتطابق مسار `src` مع مكان ملف الفيديو الفعلي. الفيديوهات التجريبية المكتوبة في الكود لا تعمل إلا بعد وضع ملفات حقيقية في المسارات المشار إليها.

## 4) تعديل الألوان

افتح `css/style.css` وعدّل متغيرات `:root` في بداية الملف، خصوصًا:
- `--color-primary`
- `--color-primary-dark`
- `--color-secondary`
- `--color-ink`

## 5) معلومات التواصل

تم إعداد رقم واتساب ورابط فيسبوك وفق البيانات المقدمة. أضف رابط Instagram الحقيقي في ملفات HTML بدل النص التوضيحي.

## 6) الاعتماد الرسمي

قسم الاعتماد في `about.html` يحتوي نصًا مؤقتًا ليتجنب نشر ادعاء غير مؤكد. استبدله بالتفاصيل الرسمية الدقيقة بعد مراجعتها.

## 7) حدود النسخة الحالية

- هذه النسخة واجهة ثابتة ولا تحتوي على تسجيل دخول أو إدارة مستخدمين.
- إضافة الفيديوهات تتطلب تعديل ملفي JavaScript يدويًا؛ لا يوجد رفع فيديو من لوحة تحكم.
- `localStorage` في المتصفح ليس مكانًا مناسبًا لتخزين فيديوهات كبيرة.
- عند نشر الموقع، يجب أن تكون ملفات الفيديو نفسها متاحة على السيرفر/الاستضافة. وجودها على جهاز المطور فقط لا يجعلها متاحة للطلاب من الإنترنت.
- الملفات داخل `videos/` ستزيد حجم المشروع إذا تم رفعها ضمن ملفات الموقع.
